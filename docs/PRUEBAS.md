# Lista de pruebas para el examen

- [ ] `GET /api/health` devuelve `success: true`.
- [ ] Traduce texto de español a inglés.
- [ ] Traduce texto de inglés a español.
- [ ] El chat alterna participantes e idiomas.
- [ ] Un mensaje vacío muestra error controlado.
- [ ] Un MP3 nuevo produce transcripción, traducción y voz.
- [ ] Un PDF con varias páginas muestra original y traducción.
- [ ] Un DOCX con títulos y párrafos funciona.
- [ ] Un TXT UTF-8 funciona.
- [ ] Una imagen nueva con texto produce lectura y traducción.
- [ ] Una imagen sin texto muestra una advertencia útil.
- [ ] Un formato no permitido se rechaza.
- [ ] Un archivo mayor de 3.8 MB se rechaza.
- [ ] El repositorio no contiene `.env` ni una clave `sk-`.
- [ ] La interfaz funciona en vista móvil.
- [ ] GitHub Pages se comunica con Vercel.
- [ ] El README contiene las URL finales.
